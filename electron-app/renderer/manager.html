사용 가이드

파일을 실제로 바꾸는 기능과 확인만 하는 기능을 작업 흐름 기준으로 정리했습니다.

1. 먼저 확인만 할 때

  • 파일 목록: 폴더 안 파일과 zip/cbz 내부 이름을 훑어봅니다.
  • 제목 중복: 같은 제목과 같은 확장자끼리만 후보로 봅니다.
  • 크기 중복: 탐색기 크기처럼 크기만 같은 파일을 찾습니다. 삭제 판단용은 아닙니다.
  • 문장 중복/참조 문장 확인: 본문이 비슷한지 보는 참고용입니다.

2. 안전한 중복 정리 순서

  • 종합 중복 정리를 실행합니다.
  • 해시 확인이 해시 일치인 행만 격리 후보가 됩니다.
  • 원하는 파일명 형식이 있으면 남김 선택으로 기준 파일을 바꿉니다.
  • 중복 후보 선택을 누르면 같은 확장자 + SHA-256 완전 일치 파일만 체크됩니다.
  • 선택 격리는 삭제가 아니라 선택 폴더 안 _FileTidier_Quarantine으로 이동합니다.

3. zip 파일이 많을 때

  • ZIP 종합 중복 정리는 내부 파일을 목록에 풀지 않고 ZIP 파일끼리 비교합니다.
  • 첫 검사에서 만든 내부 SHA-256 인덱스를 저장하며, 다음 검사부터 크기와 수정시각이 같은 ZIP은 캐시를 재사용합니다.
  • ZIP이 새로 생기거나 내용·크기·수정시각이 바뀌면 그 ZIP만 자동으로 다시 검사합니다.
  • 보관 기준은 더 많은 파일을 가진 ZIP이며, 하위 ZIP의 내용 전체를 포함합니다.
  • 전부 일치 또는 상위 ZIP에 전체 포함으로 판정된 ZIP만 격리 후보가 됩니다.
  • 같은 제목인데 구성이 다르면 검토 묶음으로 표시하며 자동 선택하지 않습니다.
  • 격리 가능 묶음만을 누르면 남길 ZIP과 격리 후보를 함께 볼 수 있습니다.
  • 분석에서 양쪽에만 있는 파일과 같은 이름인데 내용이 다른 파일을 확인할 수 있습니다.
  • 선택 격리는 내부 파일을 수정하지 않고 ZIP 파일 전체를 _FileTidier_Quarantine으로 이동합니다.

4. 이름 변경

  • 이름 변경 미리보기에서 먼저 바뀔 이름을 확인합니다.
  • 작가명 자동 추출은 파일명 패턴을 참고합니다. 애매하면 직접 작가명을 넣으세요.
  • 적용 버튼을 누르기 전까지 원본 파일명은 바뀌지 않습니다.
  • zip 내부 파일명은 직접 바꾸지 않습니다.

5. 작품 관리 화면

  • 작품 불러오기는 파일을 읽어서 목록을 만드는 기능입니다.
  • 평점, 태그, 읽음, 즐겨찾기, 리뷰 메모는 로컬 저장소에만 저장됩니다.
  • 표지 일부/전체 불러오기는 EPUB/ZIP/CBZ 내부 이미지를 썸네일 캐시에 저장합니다.
  • 웹 표지 검색은 외부 검색 사이트에 작품명이 전송되므로 확인창 뒤에 실행됩니다.

6. 아직 직접 실행하지 않는 것

  • zip 내부 항목 삭제 또는 원본 zip 재작성
  • 폴더별 자동 분류 이동
  • 압축 해제 후 자동 교체
  • 자동 감시와 자동 삭제
  • TXT 내부 중복 라인 직접 정제

패치노트

최근 반영한 기능과 일부러 제외한 기능을 한눈에 볼 수 있게 정리했습니다.

2026-07-13 ZIP 검사 캐시

변경된 ZIP만 다시 검사하도록 개선

  • 종합 중복 정리의 기본 남김 기준을 수정일이 가장 오래된 파일로 변경했습니다.
  • 내부 구성이 완전히 동일한 ZIP도 가장 오래된 ZIP을 기본으로 남기며, 더 많은 파일을 포함한 상위 ZIP은 계속 우선 보관합니다.
  • ZIP 내부 파일의 이름, 크기, SHA-256 결과를 Electron 사용자 데이터 폴더의 로컬 인덱스에 저장합니다.
  • 경로, ZIP 크기, 정밀 수정시각이 모두 같은 파일은 다음 스캔에서 내부 해시 계산을 생략합니다.
  • 새 ZIP과 변경된 ZIP만 자동 재검사하며, 결과 상단에서 캐시 재사용 수와 새 검사 수를 확인할 수 있습니다.
  • 종합 중복 정리와 ZIP 종합 중복 정리가 같은 캐시를 공유합니다.
캐시는 읽기 결과만 저장합니다. 원본 ZIP을 풀거나 수정하지 않으며, 파일 정보가 바뀌면 기존 캐시를 사용하지 않습니다.
2026-07-01 남길 후보 직접 선택

파일명 형식을 직접 고를 수 있게 개선

  • 종합 중복 정리 결과에서 원하는 행의 남김 선택 버튼을 눌러 남길 파일 기준을 바꿀 수 있게 했습니다.
  • 남김 선택을 눌러도 다른 그룹에서 이미 체크해둔 격리 선택은 유지되도록 했습니다.
  • 남길 기준을 바꿔도 같은 확장자 + SHA-256 해시 완전 일치 파일만 격리 후보로 다시 계산합니다.
  • 제목/본문만 같은 검토 항목은 남김 기준으로 선택할 수는 있지만, 해시가 맞지 않는 다른 파일은 자동 격리 후보가 되지 않습니다.
  • 3분 카레와 3분카레처럼 띄어쓰기만 다른 제목도 같은 제목 후보로 잡히도록 했습니다.
  • 분석 결과에서 본문 길이 차이와 문장 수 차이를 별도 카드로 표시합니다.
  • zip 내부 해시 점검 모드를 추가해 zip 안 파일과 외부 파일의 압축 해제 후 내용 해시가 완전히 같은지 확인할 수 있게 했습니다.
zip 내부 해시 점검은 원본 zip을 수정하지 않고 읽기만 합니다. 내부 항목 삭제/재압축은 아직 실행하지 않습니다.
2026-06-30 종합 중복 정리 안정화

분석 대기 시간과 결과 표 가독성 개선

  • 종합 중복 정리의 본문 비교가 전체 파일을 전수 추출하지 않고, 제목 후보로 잡힌 파일과 zip 내부 항목만 읽도록 줄였습니다.
  • 본문 지문 생성 단계에도 진행률을 표시해 마지막 파일에서 멈춘 것처럼 보이지 않게 했습니다.
  • zip 내부 본문 비교는 필요한 후보 항목만 읽도록 바꿔 큰 압축파일에서 오래 걸리는 상황을 줄였습니다.
  • 결과 표의 해시 열을 해시 확인으로 바꾸고, 해시 일치와 해시 미확인의 의미를 툴팁으로 분리했습니다.
  • 종합표 전용 컬럼 폭을 추가해 격리, 수정일, 위치 같은 헤더가 한 글자로 잘리지 않게 했습니다.
  • 격리 선택은 같은 확장자 + SHA-256 해시 완전 일치 파일만 가능하게 제한했습니다.
  • 제목/본문이 같아도 해시가 확인되지 않은 항목과 zip 내부 항목은 참고용 검토로만 표시합니다.
탐색기에서 보이는 크기가 같아도 실제 내용이 다를 수 있으므로, 격리/삭제 판단은 해시 완전 일치만 사용합니다.
2026-06-29 V6 참고 반영

작품 관리 편의 기능 추가

  • 추적 목록이 완전 일치뿐 아니라 비슷한 제목도 유사도 기준으로 찾아 보여주도록 개선했습니다.

2026-06-29 종합 중복 정리

확실한 중복을 찾는 종합 모드 추가

  • 제목 비교, 해시 기반 용량/내용 비교, 문장 비교를 함께 보는 종합 중복 정리 모드를 추가했습니다.
  • aaa.txt와 aaa (1).txt처럼 복사본 번호가 붙은 파일도 제목 비교에 걸리도록 보정했습니다.
  • 확실도가 높은 후보만 자동 선택하고, 실제 처리는 선택 폴더 내부의 격리 폴더로 이동하는 방식으로 유지했습니다.
  • 제목 중복 표에서 확장자가 다르면 서로 다른 파일로 보도록 조정했습니다.
